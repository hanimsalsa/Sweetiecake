🔒 Keamanan

💾 Backup & Pulihkan

📱 Cara pindah ke HP baru (data tidak hilang)
Cara A — pakai Cloud (paling mudah): di HP baru buka aplikasi → Sambungkan ke toko yang sudah ada → isi alamat server & kode toko → login dengan PIN yang sama. Semua data turun otomatis.
Cara B — tanpa Cloud: di HP lama tekan Kirim Backup (kirim ke WhatsApp sendiri/Drive). Di HP baru: buka aplikasi → Pindahkan data… (.json) → pilih file backup → masuk dengan PIN yang sama.
Tips: lakukan backup sebelum menghapus aplikasi / reset HP.
